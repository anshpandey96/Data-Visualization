# 📊 Data Visualization Project

This project showcases **end-to-end data analytics and visualization skills** using Python.  
A synthetic dataset of 1000+ sales records was generated to simulate real-world business scenarios.  
The project covers **data cleaning, exploratory data analysis (EDA), and professional visualizations** using Pandas, NumPy, Matplotlib, and Seaborn.

---

## ✨ Features
- 📂 **Synthetic Dataset**: 1000+ records with Order ID, Date, Region, State, Category, Product, Quantity, Sales, and Profit.  
- 🧹 **Data Cleaning**: Handling missing values, removing duplicates, verifying data types.  
- 🔎 **EDA Insights**:  
  - Total Sales & Profit  
  - Best Selling Product  
  - Top Region by Sales  
  - Monthly Sales Trend  
- 🎨 **Visualizations**:  
  - Bar Chart (Sales by Region)  
  - Line Chart (Monthly Sales Trend)  
  - Pie Chart (Category Distribution)  
  - Histogram (Profit Analysis)  
  - Heatmap (Correlation Matrix)  
  - Scatter Plot (Sales vs Profit)
